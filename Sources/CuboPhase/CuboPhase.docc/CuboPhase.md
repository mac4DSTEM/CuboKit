# ``CuboPhase``

Phase from 4D-STEM: the centre-of-mass reference, the rotation between scan and detector, and py4DSTEM's iterative
differential phase contrast reconstruction. The module takes centre-of-mass fields, so a measurement from any source can
enter it.
