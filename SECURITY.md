# Security policy

CuboKit reads files you give it (NumPy `.npy` cubes) and does numerical work on them. It makes no network connections.

If you find a vulnerability, for example a crash or out-of-bounds read triggered by a malformed `.npy` file, please report it
privately through GitHub's "Report a vulnerability" button on the repository's Security tab rather than a public issue.
Include a file or steps that reproduce it. We will acknowledge the report and fix it as soon as we can.

Only the latest release receives fixes.
